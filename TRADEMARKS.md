# Markenhinweise

RookyCMS nennt Produkt- und Firmennamen Dritter, um Stile, Kompatibilität und
Installationswege zu beschreiben. Diese Nennungen sind rein beschreibend.
Es besteht **keine** Verbindung, Partnerschaft, Förderung oder Empfehlung
durch die jeweiligen Inhaber.

| Name | Inhaber (im Wesentlichen) | genannt für |
|---|---|---|
| **Apple**, **macOS**, **iOS**, **iPad**, **iPhone**, **Safari** | Apple Inc. | Vorbild des Stils Graphit, Nutzung auf Tablets und Smartphones |
| **Microsoft**, **Windows**, **Fluent** | Microsoft Corporation | Vorbild und Name des Stils Fluent |
| **Ubuntu** | Canonical Ltd. | Vorbild und Name des Stils Ubuntu |
| **Nord** | Arctic Ice Studio & Sven Greb | Vorbild und Name des Stils Nord |
| **Synology**, **Web Station** | Synology Inc. | Installation auf einem NAS |
| **Apache** | The Apache Software Foundation | Webserver-Einrichtung |
| **nginx** | F5, Inc. | Webserver-Einrichtung |
| **PHP** | The PHP Group | Laufzeitumgebung |
| **GitHub**, **GitHub Pages** | GitHub, Inc. | Quellcode, Releases, Live-Demo |
| **Uptime Kuma** | das Uptime-Kuma-Projekt | Beispiel in den Demo-Kacheln |

Alle Marken gehören ihren jeweiligen Inhabern. Der Name „RookyCMS" bezeichnet
dieses Open-Source-Projekt; mit Apps oder Produkten ähnlichen Namens hat es
nichts zu tun.
